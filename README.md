# Davi | Portfólio de estudos em dados e programação

Estudante de **Análise e Desenvolvimento de Sistemas**, com foco em desenvolver competências práticas em **Análise de Dados, SQL Server, Python e visualização de dados**.

Este repositório reúne estudos, exercícios e pequenos projetos que documentam minha evolução técnica. A proposta é aprender construindo: escrever consultas legíveis, entender regras de negócio, validar resultados e melhorar soluções com base em testes.

## Áreas de estudo

- **SQL Server / T-SQL:** consultas, filtros, relacionamentos, manipulação de dados, subconsultas e controle de fluxo.
- **Python:** scripts e automações para resolver tarefas práticas.
- **Análise de Dados:** organização, interpretação e validação de informações.
- **Business Intelligence:** trilha de estudo em visualização e comunicação de resultados.

## Como organizo os estudos

Quando pertinente, cada exemplo documenta:
1. **Objetivo:** o que a consulta ou o script pretende resolver.
2. **Lógica:** como os dados são selecionados, relacionados ou transformados.
3. **Cuidados:** limitações, possíveis efeitos colaterais e validações recomendadas.
4. **Melhorias:** alternativas mais legíveis ou eficientes que valem ser comparadas.

## Ambiente e segurança

Os exemplos SQL usam nomes de tabelas de bases didáticas, como `SUCOS_FRUTAS`. Antes de executar scripts que alteram ou excluem dados, revise o código e utilize um ambiente de teste. Não inclua dados pessoais, credenciais ou estruturas confidenciais de ambientes corporativos.

## Objetivo profissional

Construir uma base sólida em dados e programação, desenvolver projetos reproduzíveis e aprender a comunicar não apenas o código, mas também o problema que ele resolve.
